RUDRAKSHA FINANCIAL SERVICES - ANDROID STARTER PROJECT

Yeh Android source project hai. APK GitHub Actions ke free usage quota ke andar build kiya ja sakta hai; GitHub account aur repository banana hoga.

DEMO FEATURES:
- Home Loan, Mortgage Loan aur Project Loan
- Customer enquiry form
- Local reference number aur application tracking
- Demo employee/admin dashboard aur status update
- Data isi phone par local save hota hai

IMPORTANT LIMITATIONS:
- Customer aur employee phones ke beech data sync nahi hota.
- Team PIN 2580 demo PIN hai; production use se pehle secure authentication zaroori hai.
- Aadhaar, PAN, bank statements, passwords ya sensitive documents is demo mein collect na karein.
- Yeh prototype hai, production-ready financial app nahi.

FREE GITHUB BUILD:
1. ZIP extract karein.
2. github.com par sign in / free account banayein.
3. New repository banayein, naam: rudraksha-financial-app.
4. Is folder ke andar ki saari files (including hidden .github folder) repository mein upload karein.
5. GitHub repository mein Actions tab kholein. Workflow "Build Rudraksha APK" run hona chahiye. Zarurat pade to "Run workflow" dabayein.
6. Build successful hone par Actions run ke neeche Artifacts mein "Rudraksha-Financial-debug-APK" download karein.
7. ZIP artifact extract karke app-debug.apk Android phone mein install karein. Phone par unknown-app installation permission maangi ja sakti hai.

NOTE:
- GitHub Actions free quota/limits apply.
- Debug APK testing ke liye hai; Play Store publishing ke liye signed release build aur developer account ki zaroorat hoti hai.
